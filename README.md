# EHR System

This project is a simple Electronic Health Record (EHR) system. It allows for managing patient information, visit details, vital signs, clinical notes, and orders (lab and radiology).

## Getting Started

To run the application, follow these steps:

1.  Install dependencies:

    ```bash
    pnpm install
    ```

2.  Start the development server:

    ```bash
    pnpm dev
    ```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.
